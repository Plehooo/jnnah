Pengaturan repo

Cara bikin token (sekali aja, ±1 menit)
1. Buka github.com/settings/personal-access-tokens/new
2. Repository access → pilih "Only select repositories" → pilih repo ini saja.
3. Permissions → Repository permissions → "Contents" → set ke "Read and write".
4. Generate token, copy, tempel di kolom di atas.
Token cuma disimpan di browser kamu sendiri (localStorage), nggak dikirim ke mana pun selain langsung ke GitHub. Jangan sebarkan link halaman ini ke orang lain selama token masih ketempel.
